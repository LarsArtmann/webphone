## What this is

A single-binary Go unified-communications web app: the proven SIP.js call island plus server-rendered tabs (Messages SMS/MMS, Fax, Voicemail, History, Contacts, Settings) on one page. Built on cqrs-htmx (root library only) + templ-components `layout.Base` + SQLite (modernc), wired through a samber/do v2 composition root (`internal/app`) with go-health probes and an optional go-health-dashboard at `/health`. The consuming stack ([nix-international-telephony](https://github.com/LarsArtmann/nix-international-telephony)) imports `nixosModules.default`, fronts the binary with TLS + the WSS `/sip` proxy, and RIDES webphone `main` (per-train lock bump); pbx-artmann consumes the stack via a rev pin. Version: `flake.nix` (`webphoneVersion`).
The cqrs-htmx `setup` bundle stays REJECTED (split-brain identity + a measured +68% binary-size NO-GO); the shell VALUE landed via `httputil.NewServer`. Evidence: docs/lessons.md.
cqrs-htmx round-3 audit (2026-10-25, score 71/100 over 5 adopted modules; supersedes the 09-19 root-only baseline): adoption is deep and deliberate; the three opportunities it flagged were ALL SHIPPED the same day by the SUPERB train: (1) `cqrshtmx.ProjectionReadinessCheck` + `ServiceConfig.OnProjectionFailed` are WIRED — /healthz carries a passkey-gated "projections" check (failed/draning projectionhost ⇒ 503 naming the worker, guard-pinned) and userauth.New logs the OnProjectionFailed WARN; (2) the identity train (usermgmt v4.16.0 + identity-model v4.14.0 + webauthn v4.13.0) is fully LANDED — both FinishLogin stubs return the used credential, WebAuthn clone detection is pinned by test (non-advancing counter ⇒ Rejection), and the durable auth-audit journal was verified queryable in a live boot (LoginFailed Auth rows in usermgmt.db); (3) `ExtensionHubs.Shutdown` (Broadcaster.Close, pre-drain in cmd/webphone) releases live /events streams instantly — restarts no longer burn the 30s drain budget with a tab open (drain test pins ≪30s). Remaining gap: the AuditLog READ projection (memory-only, unbounded — upstream ask). Refresh trigger: a bounded AuditLog projection. Report: docs/research/2026-10-25_cqrs-htmx-deep-dive.html.
go-appkit (github:LarsArtmann/go-appkit) is NOT a dependency and stays that way (audited 2026-10-23, replacing the 2026-09-24 "zero usage" observation with a per-module ruling): `core`/`health`/`realtime`/`security`/`cqrs` re-wrap libraries we already compose directly (httputil, go-health, go-sse, metaengine), `errorpages` was DECLINED because the app's 404 must render inside the session/CSRF shell with i18n (`views.NotFoundPanel`) rather than a standalone minimal page, and `otel`/`docs` solve problems this deployment does not have. - CHANGELOG bar (RATIFIED 2026-10-11): committed code-path changes get an `[Unreleased]` line — polish/one-home trains included (the 10-04 `csrf.js` and 10-06 `authedFetch` lines); test-only and docs-only deltas stay changelog-silent.
