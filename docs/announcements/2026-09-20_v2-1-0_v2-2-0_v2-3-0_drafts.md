## Draft 1 — v2.3.0 headline post (recommended single post)

**webphone v2.3.0 — honest health probes, a hardened floor, and a
drill-verified backup story**

webphone is a single-binary Go unified-communications web app: the
proven SIP.js call island plus server-rendered Messages, Fax,
Voicemail, History, Contacts and Settings tabs on one page.

Three releases landed tonight (v2.1.0, v2.2.0, v2.3.0); v2.3.0 is the
one to deploy. Highlights:

- **Honest readiness**: `/healthz` names the failing check (sqlite
  ping, blob-dir write probe) instead of a bare 503, plus new `/livez`
  and `/startupz` probes with per-check timeouts — friendly to
  systemd, nginx and fleet health hubs.
- **Daily online backups, drill-verified**: a NixOS-module timer takes
  a sqlite `.backup` snapshot and rsyncs the blob tree while the phone
  keeps running. The restore path was proven end to end by an automated
  drill (real binary, binary attachment, tar, restore, reboot,
  byte-identical pull).
- **Security fix (v2.2.0, important)**: login now verifies submitted
  credentials against the PBX directory before minting a session.
  Previously the endpoint trusted the browser's claim that a SIP
  REGISTER had succeeded, so a forged request could open a session for
  any extension and read that extension's messages, faxes and
  contacts. Found by live-probing a production deployment.
- **Go 1.27.1 floor** and refreshed dependencies (nanoid v1.65.1).
- Nginx vhost hardening options (HSTS), request-ID in every log line,
  calibrated Permissions-Policy that keeps the WebRTC microphone alive.
