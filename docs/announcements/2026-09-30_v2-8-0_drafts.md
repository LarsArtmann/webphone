## Draft B — v2.8.0 headline post

**webphone v2.8.0 — errors that classify themselves, a wire that tells
the truth, and a quieter disk**

webphone is a single-binary Go unified-communications web app: the
proven SIP.js call island plus server-rendered Messages, Fax,
Voicemail, History, Contacts and Settings tabs on one page.

The theme of this train: make the invisible surfaces honest —
error identity, wire metadata, and file permissions — so every
consumer (operator, bridge, forensic grep) stops guessing.

- **Errors with identity.** Every internal error constructor now
  builds a classified error with a stable `seam.code` identity
  (`store.list_messages`, `session.verify`, …) while the rendered
  strings, HTTP statuses and the classification ladder stay
  byte-pinned by tests. Operators grepping logs get the family
  prefix for free; callers branching on errors get sentinels that
  never changed.
- **The wire stops lying about file parts.** Webhook- gateway
  attachments and faxes now carry their honest Content-Type (the
  attachment's stored mime; faxes are `application/pdf`) instead of
  the generic octet-stream Go stamps by default. Producing sides
  own their types; consuming bridges can retire magic-byte
  sniffing.
- **Private comms data is not world-readable.** Both systemd units
  now run with `UMask=0077` and `StateDirectoryMode=0750` — message
  threads, faxes, voicemail blobs and the session database land
  closed on disk. Backup snapshots order after the service so a
  boot-time catch-up cannot race the database into existence.
- **NixOS module: Caddy, not nginx.** The module's optional vhost
  generator now builds a Caddy vhost (automatic HTTPS, sane
  compression, unbuffered SSE) and a `caddy.sipUpstream` option that
  finally bridges the SIP WebSocket to the PBX instead of dead-ending
  at the app. The old nginx generator had zero real users; the
  telephony stack fronts the app itself.
- **A flake you can read.** The 803-line `flake.nix` split into
  focused modules under `nix/` (packages, checks, devshell, …)
  without changing any output.
- **Plus the staged 2.7.0 content:** self-addressed messages and
  faxes refused instantly with the evidence kept, shared contacts
  back in the dial typeahead, EmptyState adoption with a
  coexistence-proven scoped Tailwind build, bounded uploads,
  redacted 500s, Retry-After hints.

Single-tenant PBX product; if you run it, the upgrade notes live in
the CHANGELOG (the module rename is the one breaking edge — option
`nginx.*` became `caddy.*`).

https://github.com/LarsArtmann/webphone/releases/tag/v2.8.0
