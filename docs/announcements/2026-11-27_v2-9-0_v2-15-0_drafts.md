## Draft B — v2.9.0 → v2.15.0 headline post

**webphone v2.15.0 — a phone that remembers everything, honestly**

webphone is a single-binary Go unified-communications web app: the
proven SIP.js call island plus server-rendered Messages, Fax,
Voicemail, History, Contacts and Settings tabs on one page — deployed
from one NixOS module behind Caddy.

The seven releases since v2.8.0 carry two big stories.

- **One journal world.** Every domain answer — threads, messages,
  attachments, fax jobs, personal contacts, call transcripts, call
  notes and reviews, snippet lists, enroll tokens, agent audit rows,
  push devices, the dedup windows — now projects from event-sourced
  journal streams in ONE `system.db`. Legality lives in declarative
  state machines (outbound delivery, fax lifecycle, thread append),
  webhook replays converge durably instead of in a process's memory,
  and retention tombstones expired data out of the views AND out of
  the journal bytes. Each swap shipped complete: a one-time importer
  pinned by a row-by-row dual-run parity diff, the SQL store kept as
  import source, snapshots and metrics re-pointed, and an upgrade
  chain documented for deployments with pre-existing data. The
  retired engine's database became an inert orphan, and a new
  `webphone export-legacy` CLI exists as the DROP-window safety tool.
- **The first visible redesign.** The desk-phone vernacular train
  replaced every platform-emoji icon with consistent SVG strokes and
  stretched panels into desk surfaces; the green-identity train (the
  owner's brand ruling — indigo was vetoed same-day) brought the
  segmented icon tab bar, an icon-over-label mobile bottom bar that
  fits eight tabs on a 390px screen, content-first phone layout with
  the dialer island always reachable, pill-shaped actions, tonal
  surfaces and an elevation ladder with motion tokens; and the
  sidebar-rail train docked a grouped rail on desktop, added the
  multi-line ownership model (a "My account" view, a line switcher,
  admin inventory over the same one model) and made the login front
  door a single passkey-or-password page.

Also worth naming: the Reports tab stopped lying about time (a CDR
timestamp parser fix behind an honest "time views unavailable"
state), names top talkers from your own address book first, and
counts the calls that never connected; a stale SIP agent can no
longer double-ring the island after a storm of failed registrations;
voicemail play failures surface one honest toast instead of a dead
button; call notes autosave as the operator types; and the Android
shell vendors byte-pinned wire fixtures so a renamed key reds a local
test instead of the first device boot. The browser E2E lane is now a
blocking CI job, projection dead-letters are observable, and the
backup set covers every database the product actually writes.

v2.15.0 is live on the reference deployment (verified by the stack's
no-ssh readback: 97 checks pass, 0 fail). Still deliberately off on
that box: live transcription and the xml_curl credential cutover.
