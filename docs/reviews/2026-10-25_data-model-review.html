02Problem catalog

The 10-14 thesis was "vocabularies that live in comments and string comparisons instead of types". Every finding below is that thesis recurring in code the review predates (the chat-network, push and SSO trains landed after it), plus one detector blind spot the series should stop re-litigating.

Adopt · P4/P5

push.Transport: a closed vocabulary living as map keys and params

internal/push/push.go:116,136 · internal/readmodels/push.go:88

"ntfy" and "fcm" are a closed, repo-owned vocabulary: they key the Fanout registry (senders map[string]Sender), flow through Knows and Send, get validated by the device-registration API, and name themselves in error codes. Yet the type is string end to end, so Send(ctx, transport, target, ring) can swap its second and third string silently. This is exactly the class the 10-14 review converted into enums (gateway.Resolution, FailureKind).

Fix Defined type push.Transport with two constants and a ParseTransport door; the registry becomes map[Transport]Sender. The readmodels storage schema stays raw (engine-row doctrine, directives already in place).
Adopt · P2-adjacent

sso.Complete re-scatters the Challenge it minted

internal/sso/sso.go:159

Begin mints Challenge{URL, State, Nonce, Verifier}, a value object. Complete takes the values back as three loose strings: Complete(ctx, code, verifier, nonce). On the authentication-critical path, a verifier/nonce transposition compiles and weakens or breaks sign-in. FaxDelivery exists for precisely this shape of risk.

Fix Value object sso.Finish{Code, Verifier, Nonce} assembled at the callback door. Lands under the auth-regression convention: auth: commit prefix and the session-behavior suite.
Adopt · P4

FaxJob.DocumentPath is still raw beside a landed brand

internal/domain/fax.go:119,146

The 10-14 review landed domain.RelPath and this series verified it in use at three blob edges, including domain.MustParseRelPath(job.DocumentPath). The FaxJob field itself stayed string, so NewInboundFaxJob still carries the documentPath / providerRef transposition pair the tool flags.

Fix Type the field as domain.RelPath; the store scan converts with ParseRelPath (corruption crashes loudly, the MustThreadID doctrine).
Adopt · P4, bounded

Constructor string-trains in the new seams (asr, matrix)

internal/asr/asr.go:137 · internal/matrix/client.go:64

NewWhisperCppClient(baseURL, token, model) and matrix.New(homeserver, userID, token) are three same-typed strings each, wired once from config at boot. A swap surfaces as broken wiring at first use, not at compile time. The services must stay config-free (the userauth doctrine), so the fix is a package-local wiring struct, not the config type.

Fix Small param structs (asr.Wire, matrix.Wire) at the constructor door; app/chat.go and app/app.go assemble them from the config fields they already read.
Adopt · trivial

machineSurface: bool parameter not last

internal/server/internal_directory.go:40

The one-home helper takes its enabled flag mid-signature. Reordering costs one line and kills the positional-confusion finding.

03The vision

Every repo-owned vocabulary is a defined type with its parser at the door; every value that crosses a seam as a bundle travels as a value object; every deliberate raw string carries its written reason. After this roadmap: the push registry is keyed by a type, the OAuth finish path is a struct, the fax row carries the path brand it already uses, and the baseline records why the rest stays as it is.

06Validation layer

ParseTransport joins the established parser family (ParseExtension, ParsePhone, ParseAddress, ParseRelPath, the Must* row readers): validation lives at the door, corruption crashes loudly, and the zero value is never a silently accepted state. The registration API's existing 422-on-unknown-transport prose becomes a type-backed guarantee, and the dialplan ring hook keeps failing closed with a named code.

07Decision log

DecisionRationaleRejected alternative
Transport lives in push, not domain It is a push-local delivery vocabulary; domain holds cross-seam concepts (Network, Address, Phone). readmodels keeps the storage-schema string, so no layering edge is crossed. domain.Transport: drags a push detail into the domain package for zero extra safety.
sso.Finish value object, not branded string types The bundle is the invariant (code + verifier + nonce travel together from one browser flow); FaxDelivery set the precedent. type AuthCode string etc.: three new brands to thread through cookies for the guarantee a struct gives.
FaxJob.DocumentPath becomes RelPath The brand already exists and is in use at this very call site; typing the field deletes a parse door instead of adding one. Keep string + MustParseRelPath at use: the tool keeps flagging the constructor pair, honestly.
Wiring structs instead of per-string brands in asr/matrix Two-call-site boot wiring; a struct kills the swap and reads as one fact (the provider wiring), matching the config-free doctrine. type BaseURL / Token / Model brands: the BD003 mechanical-brand trap this repo already ruled against.
Baseline the edge doors and seam interfaces ParseToken at the scan door, BearerGate's two strings, and the six Deps seams are ratified design; a detector that cannot see tests should not veto architecture. Restructuring to satisfy the tool: un-makes nil-safety and test seams to silence an info finding.
signal.New and ntfy stay two-string constructors Two params, one call site each, boot-fail-fast inside the smoke; a struct there is ceremony without a failure mode. Uniform structs everywhere: uniformity for its own sake is the over-engineering the series warns about.

08Anti-patterns to keep avoiding

Mechanical brand minting

The tool suggests a brand for every raw string; the doctrine says brands only where a domain identity exists (BD003 directives carry the reasons). Every suggested-but-unminted brand in this report's findings is deliberate.

Typed-constant smuggling

A const TransportNtfy = "ntfy" next to string params is documentation, not type safety. The constant must carry the type (Transport) and the map key must demand it.

Refactoring to please a detector

Single-implementer seam interfaces and edge-door conversions are architecture. Baseline them with reasons; revisit only when a second implementer actually arrives.
