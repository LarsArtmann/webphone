## e) WHAT WE SHOULD IMPROVE

1. **Verification loops must be cache-proof.** Always `go test -count=1`; never pipe a gate through `grep`/`tail` without also seeing the raw summary. (Cost when ignored: ~10 minutes of confusion this session; worse next time.)
2. **Preserve failure evidence before re-running.** Any panic dump goes to a per-run file (`/tmp/dump-<n>.txt`), never a reused name. The hang's best evidence was destroyed by my own re-run.
3. **Read unexpected diffs immediately.** An uncommitted change you didn't author gets read _before_ it can vanish into a daemon commit, not after.
4. **Commit per task when authorized** — the daemon's heuristic commits do not tell the story of _why_; explicit small commits do.
5. **Pin greppable contracts with tests.** Operator-facing strings (error texts, log lines, the 401 body) are runbook surface. If a runbook greps it, a test owns it. This session silently changed provider error texts (`close fax form:` → `close provider form:` inside a new `build fax form:` prefix) — behavior-equivalent for tests that exist, but only luck keeps runbooks working.
6. **One accepted-clone register.** The 7 accepted art-dupl groups should be a one-line-each note (AGENTS.md), so the next session triages zero of them again.
7. **Decide and document the gating policy** (dual-layer vs single-layer). Right now the rationale lives only in a code comment.
8. **DRY sweep backlog observed while reading (not flagged by art-dupl, `-t 1` blind spots):** `pbx.Credentials{Extension: sess.Extension.String(), Password: sess.Password}` built inline in 4 places; the `threadPanel` render-or-error block duplicated between actions.go:63-75 and panels.go:61-69; the file-streaming tail (Content-Disposition + `io.Copy`) duplicated in `faxDocument`/`attachment`.
9. **The magic string `"sign in first"` exists in two places** (server `requireSession` and `session.Store.Require`). Small split brain; one exported constant in the session package would collapse it.
10. **`docs/research/2026-09-18_cqrs-htmx-deep-dive.html`** embeds the old inline-gate snippet as example code; it is a dated research doc, but a "historical, pattern since superseded" note would prevent cargo-culting.
