05e · What we should improve

Coverage reporting hides the truth it should reveal

buildflow's test-coverage step writes per-package numbers; the cross-package reach of the integration suite (the actual test strategy here) is invisible. Add a -coverpkg=./... union pass so the reported number is the real one (48.3% / 57% hand-written), and consider a regression threshold.

server_test.go is becoming a god file

761 lines, 14 tests, every concern in one file — and it holds the repo's only jscpd clone (14 duplicated helper lines). Split by concern (sse_test, webhooks_test, proxy_test, session_test) before it doubles; extract the helper while splitting.
