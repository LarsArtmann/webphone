00Summary

webphone chose the pure-Go SQLite driver for a structural reason: no cgo means the flake cross-builds aarch64-linux from the same source without per-arch toolchain work, and the sandboxed Nix build needs no C toolchain for the app. Usage is concentrated in one file (internal/store/db.go) and is correct where it matters: WAL + busy_timeout + foreign_keys are set at open, writes serialize through a single connection, and the schema enforces the provider-ref idempotency invariants with partial unique indexes.

Bottom line Correct and idiomatic for the product's scale. Two cheap wins exist (synchronous pragma decision, a schema-version table); the rest of the gap surface is features this single-node product genuinely does not need.

Error mappingUsedsql.ErrNoRows mapped to store.ErrNotFound at every read path (erraudit-clean, sentinel matching per the Go 1.26 decision tree).
Prepared statementsNot usedEvery call is ExecContext/QueryContext. At this traffic (per-extension, single node, MaxOpenConns=1) re-parse cost is noise; adopting sql.Stmt caches would add lifetime plumbing for no measurable win.
PRAGMA synchronousNot setDefault (FULL in WAL terms) favors durability — the right default for messages/faxes. A deliberate NORMAL could buy latency if the operator ever complains; today there is no such complaint, so leaving it is correct.
Backup/online-copy APINot usedThe backup story is a TODO_LIST item (rsync/restic pattern + restore drill). When it lands, decide between file-copy-under-lock and VACUUM INTO; the driver exposes both paths.
Schema versioningNot usedmigrate() is idempotent CREATE IF NOT EXISTS — fine while the schema only grows. The first destructive/altering migration will need a schema_version table; adding it now is 20 lines and removes a future surprise.
User-defined functions / collationsNot applicableNo query needs custom collation; search rides LIKE in Go-filtered result sets.

02Risk assessment

Known trade, consciously held A pure-Go driver is slower than mattn/go-sqlite3 (cgo) and lags upstream SQLite releases by weeks. For a per-extension telephony sidecar those costs are invisible; the cross-build and sandbox wins are not. govulncheck reports 0 reachable vulnerabilities in the required module set.

Version currency: go list -m -u reports no update for modernc.org/sqlite — the repo is current. The libc companion modules (modernc.org/libc et al.) ride transitively and are covered by the same scan.
