## schema_version mechanism (T25.1)

```sql
CREATE TABLE IF NOT EXISTS schema_version (version INTEGER NOT NULL);
```

- `migrate(ctx, db)` becomes a versioned runner: read version (no row =
  legacy DB), apply steps `v+1 … latest`, each step ONE transaction, then
  stamp. Failure aborts at its step (atomic per step; retry safe).
- v1 (baseline, duplicate-tolerant): the existing CREATE TABLE set +
  the failure columns — exactly today's behavior, so a legacy DB (or a
  fresh one) converges to v1 without knowing its history.
- v2 (strict, transactional): `ALTER TABLE threads ADD COLUMN
  pinned/archived/muted INTEGER NOT NULL DEFAULT 0`; `CREATE TABLE IF
  NOT EXISTS snippets …` + its index. Strict because the version row
  guarantees single application; the CREATE stays IF NOT EXISTS
  (idempotent by nature).
- Migration tests: fresh DB → latest; legacy DB (tables, no version
  row) → stamps + converges; already-latest DB → no-op; a v2 rerun
  never duplicates columns.

## Store surface (new/changed)

- `domain.Thread` += `Pinned, Archived, Muted bool`.
- `domain.Snippet{ID, Owner, Body, Quick, CreatedAt}` +
  `GenerateSnippetID` (go-branded-id, the contacts pattern).
- `Messages.SetThreadFlag(ctx, owner, id, flag, on)` — one method,
  flag ∈ {pinned, archived, muted} (enum), zero rows → ErrNotFound
  (updatedOrNotFound). Auto-unarchive rides AppendMessage's upsert
  (`archived = 0` when the inserted direction is inbound).
- `ListThreads/SearchThreads`: `ORDER BY pinned DESC, last_activity_at
  DESC`; archived excluded unless `IncludeArchived` option.
- Summary scan += the three flags + `LastAttachment bool`.
- `Snippets` store: `List/Save(upsert by body? no—by id)/Delete`,
  cap 100 per extension (ErrListFull, the contacts pattern). Save =
  insert-or-replace by id (edit = delete+re-add in the UI; keep the
  seam minimal).

## Server surface (changed only, no new files)

- `POST /messages/{id}/pin|archive|mute` → toggle (form value `on`) →
  204 + `threads` SSE nudge (the contacts-nudge epilogue) + unread
  cache drop when the flag is mute.
- `POST /snippets/save`, `POST /snippets/delete` → settings partial
  re-render (toast + partial, the saveContact pattern).
- `countUnread` skips `summary.Muted`.
- Routes + openapi.json entries + contract allowlist unchanged (no new
  401 writer FILES).

## View surface

- ThreadRow: stable wrapper id, pin/mute/archive mini buttons (aria
  labels en/de), muted row suppresses the unread badge and shows a 🔇
  marker, archived list renders an "unarchive" affordance.
- ThreadsPanel: "Archived (N)" toggle link when N > 0.
- Composer: `<details>` snippet picker + quick-reply chips (quick=1,
  render above the textarea, cap 5).
- Settings tab: snippets section (list + add/edit-delete form).
- Transcript: image attachments get the lightbox dialog wrapper.
- i18n: every key lands in en AND de (sync test enforces).
