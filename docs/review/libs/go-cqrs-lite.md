## What the library offers (the consumed modules)

- **system/v4**: `system.New(ctx, Domain(decls…), DeploymentConfig)` composition root — journal store, bus, projection hosting, snapshot wiring, health/status; the deployment declares engines + instances by role (webphone: one sqlite engine, source-of-truth + projections instances, internal/app/cqrs.go:209-231); `RegisterDecider[S]` + `RegisterCommand` + `system.RawQuery` projection declarations (12 decls); `sys.Dedup()` (durable CAS window) + `sys.MetaEngine()` (the raw engine seam behind counts/caps); `sys.TrimStream` (retention: journal bytes leave the store); `system.Domain(decls...)` composes aggregate declarations.
- **event/command/decider/v4**: the machine-table core — `decider.Decider[S]{Initial, Decide, Apply}` decides legality from state; commands carry an `ID()` METHOD; webphone's legality tables (`deliveryMoves`/`faxMoves`/`AppendToThread`) are consumed verbatim at the decision.
- **projectionhost/v4**: declarative projection registration (`ProjectionHostOptions` + `FilterOnField`/`SortOnField` declarations); the SQLite dead-letter store (`NewSQLiteDeadLetterStore` — the poison lane, internal/app/cqrs.go:203); readiness surface feeds the passkey-gated `/healthz` "projections" leg.
- **snapshot/v4**: `EveryNEvents(200)` + `NewReadPressure(50, WithInnerStrategy(every))` — the resolved D8 strategy (grind 3.3 ms → 0.84 ms, measured in the plan errata).
- **metaengine/v4**: `Query[Q,R]` declarations (14) + folds/Remove, `TypedReader` ScanOptions, capabilities DedupStore + AggregateReader, **`WithCapPerGroup`** (per-group declarative caps, the #114 product), `WithCap` (declarative GLOBAL ceilings), `EnforceCaps` (the engine's cap-maintenance pass — store-driven after append), `Volume` (sizing hints), `WithLimit` (default scan ceiling 100 — load-bearing).
- **sqliteengine/v4**: `NewFromDSN` (WAL pragmas); planned tables `meta_planned_<collection>`; implements the capabilities (asserted at boot).
- **catalog/v4 + record/v4 + id/v4**: the OpenAPI/AsyncAPI/EventCatalog export lanes; the Record envelope + StreamRef (retention refs); branded ids.

## Ruling

The doctrine INVERTED with SUPERB: every new aggregate grows on the system composition root (`cqrs` package + `system.Domain` decl + decider + projections + retention leg), never as a new SQL table — the storage ladder is FROZEN and now COMPLETE (docs/planning/2026-11-09_storage-ladder-retirement.md; sessions stay SQL per D2; the readmodels engine is gone, readmodels.db an inert orphan). Upstream's core/v5 finalization is the live forward item: when the v5 train cuts, re-run this audit against the codemod output before riding it.

**Refresh trigger:** the per-CALL nested-addressing cap ask (upstream); the core/v5 tag train (record/id/event surface rewrite — plan the codemod pass); any owner crossing ~10k rows per collection (keyset pagination); a second engine (failover/backfill).
